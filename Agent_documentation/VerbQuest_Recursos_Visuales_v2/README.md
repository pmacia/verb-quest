# VerbQuest — paquete completo para comenzar el desarrollo

Este ZIP contiene los requisitos funcionales, la dirección visual seleccionada, las propuestas gráficas, los wireframes SVG editables, los tokens de diseño, los esquemas de datos y las semillas de ejemplo.

## Empieza aquí — documentos visibles en la raíz

1. **`REQUISITOS_FUNCIONALES.docx`** — documento de lectura y revisión.
2. **`REQUISITOS_FUNCIONALES.md`** — misma especificación en Markdown, recomendada para un agente de programación.
3. **`README_PARA_AGENTE.md`** — instrucciones de desarrollo, orden de implementación y criterios de terminado.
4. **`DIRECCION_VISUAL.md`** — registra qué diseño se ha elegido y qué detalles aprovechar de las otras propuestas.

No es necesario buscar estos documentos dentro de carpetas: las copias principales están directamente en la raíz del ZIP. También hay copias en `docs/` para mantener una estructura de proyecto convencional.

## Decisión visual

La **segunda propuesta visual** es la referencia principal seleccionada. Véase `design/visual-explorations/00-DIRECCION-VISUAL-PREFERIDA.png`. Se mantiene el estilo azul, la ilustración de adolescentes, la presentación modular y la composición de pantallas. De otras propuestas se incorporan detalles útiles de juegos, sellos, progresión, filtros, ficha del verbo y navegación. El nombre de trabajo en producto/código debe ser **VerbQuest**; “VerbMaster” e “Irregular Verbs Pro” aparecen únicamente en exploraciones anteriores.

## Contenido

- `design/visual-explorations/`: tableros de propuestas y síntesis visual complementaria.
- `design/assets/`: logotipo e icono editables, sellos, wireframes de catálogo/plan/juego, tokens CSS y JSON.
- `docs/`: propuesta de producto y copias de requisitos.
- `schemas/`: esquemas JSON iniciales del verbo y del plan de estudio.
- `examples/`: verbos de prueba, lista CSV, plan y preguntas de ejemplo.

## Precauciones

Los pósteres son referencias visuales, no especificaciones textuales definitivas. Pueden contener textos diminutos, datos inventados o errores lingüísticos. La especificación funcional y los esquemas prevalecen. El conjunto de ocho verbos es una semilla técnica, no un catálogo escolar completo ni validado. Antes de publicar, se deben revisar niveles, frecuencia, IPA, variantes y frases de ejemplo. No se incluyen audios de terceros.
