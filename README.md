# VerbQuest

Aplicación educativa local para practicar verbos irregulares. Desarrollo activo según el diseño y plan en docs/superpowers.

Node 24, npm. Instalar con `npm ci`; ejecutar `npm run dev`; comprobar con `npm test`, `npm run typecheck` y `npm run build`. No hay cuentas ni sincronización. Los datos se guardan en el navegador; exportar copias antes de borrar su almacenamiento. Los fixtures no son un catálogo escolar validado.
