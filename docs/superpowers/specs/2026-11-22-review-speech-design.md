# Interpretación del dictado en repaso

Diseño acordado en conversación y autorizado para implementación.

Objetivo: repasar formas irregulares con fluidez para principiantes hispanohablantes; no calificar pronunciación usando el texto del navegador.

Enfoques: validación literal (frustrante), corrección difusa automática (falsos aciertos), interpretación graduada (elegida). Coincidencias exactas y homófonos seguros se aceptan automáticamente. Separaciones como «a woke» se unen solo si forman exactamente la respuesta esperada. Confusiones como «being» por «been» y alternativas secundarias se ofrecen para confirmar, nunca se aceptan automáticamente. Las respuestas distintas siguen siendo distintas.

Tres casillas conceptuales, no necesariamente tres palabras. «was», «were» y «was were» son respuestas de pasado válidas. La segmentación consume todo el texto, conserva el orden y tiene límites de longitud. La escritura sigue estricta. No cambiar captura, permisos, temporización ni introducir IA.

Interfaz: conservar transcripción dudosa editable y sugerencias por casilla. Comprobar abre una confirmación integrada cuando todas las casillas se podrían resolver con sugerencias; confirmar acepta como respuesta asistida. Permitir evaluar la transcripción original o volver a editar. Las sugerencias y confirmaciones se recalculan tras editar; nunca sobreviven a una nueva pregunta.
